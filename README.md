# Fraudulent Assets Watchlist

This repository contains a list of domains linked to suspicious or malicious assets on the Stellar network. These domains have been flagged based on reports from users and community members.

All assets issued under any domain listed here have been blacklisted in **LOBSTR** to protect users and reduce exposure to fraudulent activity.

**If you believe your project was added by mistake, please contact us at [listings@lobstr.co](mailto:listings@lobstr.co).**

---

## About the List

- The full list of flagged domains is available in [domain-list.txt](domain-list.txt).
- Each entry in the file is either:
  - a specific domain (e.g., `example.com`, `assets.example.com`), or  
  - a wildcard domain (e.g., `*.example.com`) that covers all subdomains, such as:
    - `xyz.example.com`
    - `abc.example.com`
    - `assets.abc.example.com`
    - and also the root domain `example.com` itself.

## Contributing

We are actively expanding this list based on incoming reports.

To suggest a domain or asset for review:

- Open a new [GitHub issue](https://github.com/Lobstrco/fraudulent-assets/issues/new/choose).
- Include:
  - the domain or asset code,
  - a short explanation,
  - any supporting details or links that justify the flag.

**Note:** Do not submit pull requests. Use the issue tracker for all suggestions.
